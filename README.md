# DeepFER
DeepFER is a deep learning-based Facial Emotion Recognition (FER) system that classifies facial images into seven different emotional categories using Convolutional Neural Networks (CNNs) and Transfer Learning.

The project explores two approaches:

Custom CNN – A CNN model developed from scratch as a baseline.
MobileNetV2 – A lightweight pre-trained CNN using Transfer Learning.

The models are trained and evaluated on facial images representing seven emotions: Angry, Disgust, Fear, Happy, Neutral, Sad, and Surprise.

The project demonstrates an end-to-end computer vision workflow, including data preparation, preprocessing, augmentation, model development, training, evaluation, comparison, and deployment.
